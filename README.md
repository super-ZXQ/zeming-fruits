# 泽明果业微信小程序

水果线上预约小程序。顾客可以查看实时价格、提交到店自取预约，或选择 3km 内送货上门（配送费固定 ¥5）。小程序不提供在线支付。

## 核心流程

1. 顾客通过微信手机号授权登录。
2. 商品加入预约单，在确认页由服务端重新核验价格、库存、上下架和配送范围。
3. 顾客提交预约，商家按“待确认 → 已确认 → 备货”处理。
4. 自取订单进入“待取货”，配送订单进入“配送中”，顾客收到商品后确认完成。
5. 待确认预约可由顾客取消；确认后需联系商家处理。

## 云函数

- `userLogin`：会话检查、手机号授权和管理员身份迁移。
- `customerProfile`：地址的新增、修改、删除和默认地址管理。
- `createReservation`：实时报价、3km 校验和幂等预约提交。
- `customerOrders`：顾客取消、确认收货和申请售后。
- `adminAuth`、`adminProducts`、`adminOrders`、`adminManagers`：后台鉴权和管理功能。

## 首次部署

正式云环境：`cloud1-d2gkep1yz4b62ba1e`。

1. 在微信开发者工具中关联上述云环境。
2. 部署上述云函数，选择“云端安装依赖”。
3. 创建 `users`、`addresses`、`products`、`orders`、`settings`、`admins`、`managers` 集合。
4. 按 `database/schema.json` 创建索引，尤其是 `orders(_openid, requestId)` 唯一索引。
5. 将 `cloud/*.permissions.json` 对应规则应用到数据库集合。
6. 在 `admins` 集合配置首位店主：`{ "adminOpenids": ["店主 OpenID"] }`。
7. 在微信公众平台配置用户隐私保护指引，说明手机号、位置、地址、联系人和订单信息用途。

## 上架前检查

- 真机验证手机号授权、拒绝授权、地址选择和管理员登录。
- 验证到店自取、3km 内配送、3km 外拦截和重复提交。
- 验证待确认取消、自取待取货、配送完成和售后处理。
- 运行微信开发者工具预览，确认无编译错误和隐私字段错误。
